# Snip frontend

Angular 19 client for Snip. It validates HTTP(S) URLs, creates short links, and
lists links with their hit counts.

Run `npm install` and `npm start` to serve the app at `http://localhost:4200`.
The development server proxies `/api` requests to `http://localhost:3000`.

Run `npm run build` to generate `dist/snip-frontend/browser`, or `npm test` for
the component tests.
